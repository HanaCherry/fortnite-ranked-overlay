## จากตัวจำลองสูโอเวอร์เลย์

คลังนี้เริ่มจากเครื่องคิดคะแนนแรงก์ ตอนนี้เป็นสตูดิโอโอเวอร์เลย์สำหรับสตรีมเมอร์ ตัวจำลองเดิมยังอยู่ที่นี่ทุกภาษา

## สตูดิโอแรงก์ ไม่ใช่แค่เครื่องคิดเลข

- **แรงก์และความคืบหน้า** — จาก Bronze III ถึง Unreal Legends, Builds หรือ Zero Build — มือหรือจากโปรไฟล์สาธารณะ
- **โอเวอร์เลย์ OBS** — แบนเนอร์ เต็ม หรือกะทัดรัด พื้นหลังโปร่งใส พร้อมเป็นแหล่งเบราว์เซอร์
- **ซิงก์ Fortnite Tracker** — อ่านโปรไฟล์สาธารณะได้ตามต้องการ ไม่มีชื่อก็ใช้โหมดมือได้ทันที
- **7 โลก 6 เหรียญ** — คลาสสิก กาแล็กซี นีออน น้ำแข็ง รอยัล มินิมอล กาแล็กซีดวงดาว สัญลักษณ์แรงก์ไม่เปลี่ยน
- **เป็นส่วนตัวตั้งแต่ดีไซน์** — เซิร์ฟเวอร์ฟังแค่ 127.0.0.1 ชื่อและประวัติอยู่ใน data/ Git จะไม่เก็บ
- **เซสชันสด** — คิล เดธ สตรีค และโทสต์เลื่อนแรงก์ระหว่างสตรีม

## เริ่มใน 4 ขั้นตอน

Node.js 18 ขึ้นไป บน Windows ใช้ LANCER.bat ได้หลังติดตั้ง

```sh
git clone https://github.com/HanaCherry/fortnite-ranked-overlay.git
cd fortnite-ranked-overlay
npm install
npm start
```

http://127.0.0.1:8767

## OBS / Streamlabs

1. เปิดแอปแล้วทิ้งไว้ระหว่างสตรีม
2. คัดลอก URL โอเวอร์เลย์จากแท็บ OBS
3. เพิ่มแหล่งเบราว์เซอร์
4. วาง URL พื้นหลังโปร่งใสตามค่าเริ่มต้น

ขนาดแนะนำ: 700 × 220 (แบนเนอร์) · 1100 × 220 (เต็ม)
