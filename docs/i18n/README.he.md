## מסימולטור לשכבה

המאגר התחיל כמחשבון נקודות ראנקד. עכשיו זה סטודיו שכבות לסטרימרים. הסימולטור המקורי נשאר כאן בכל השפות.

## סטודיו ראנקד, לא רק מחשבון

- **דרגה והתקדמות** — מ-Bronze III עד Unreal Legends, Builds או Zero Build — ידני או מפרופיל ציבורי.
- **שכבת OBS** — באנר, מלא או קומפקטי. רקע שקוף, מוכן כמקור דפדפן.
- **סנכרון Fortnite Tracker** — קריאה אופציונלית של פרופיל ציבורי. בלי שם, המצב הידני עובד מיד.
- **7 עולמות, 6 תגים** — קלאסי, גלקסיה, ניאון, כפור, רויאל, מינימל, גלקסיה כוכבית. סמל הדרגה לא משתנה.
- **פרטי לפי עיצוב** — השרת מאזין רק ב-127.0.0.1. שם והיסטוריה ב-data/, Git מתעלם.
- **סשן חי** — הריגות, מוות, רצף והתראות עליית דרגה בזמן השידור.

## עולה ב-4 שלבים

Node.js 18 ומעלה. ב-Windows מספיק LANCER.bat אחרי ההתקנה.

```sh
git clone https://github.com/HanaCherry/fortnite-ranked-overlay.git
cd fortnite-ranked-overlay
npm install
npm start
```

http://127.0.0.1:8767

## OBS / Streamlabs

1. הפעילו את האפליקציה והשאירו אותה פתוחה בשידור.
2. העתיקו את כתובת השכבה מלשונית OBS.
3. הוסיפו מקור דפדפן.
4. הדביקו את הכתובת. הרקע שקוף כברירת מחדל.

גודל מומלץ: 700 × 220 (באנר) · 1100 × 220 (מלא).

## סימולטור הראנקד נשאר באינטרנט

העריכו נקודות לפי מיקום, הדחות, שלב מאוחר ודרגת יריבים. חינם, בלי התקנה, בשפה שלכם.

[פתחו את הסימולטור](https://hanacherry.github.io/fortnite-ranked-overlay/simulateur.html?lang=he)

## נתונים מקומיים

ה-config.json המצורף בלי חשבון. הגדרות ב-data/config.json, היסטוריה ב-data/state.json. התיקייה לא מתפרסמת לעולם.
