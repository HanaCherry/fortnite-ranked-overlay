## सिम्युलेटर से ओवरले तक

यह रेपो रैंक्ड पॉइंट कैलकुलेटर के रूप में शुरू हुआ। अब यह स्ट्रीमर्स के लिए ओवरले स्टूडियो है। मूल सिम्युलेटर यहाँ हर भाषा में है।

## सिर्फ़ कैलकुलेटर नहीं, रैंक्ड स्टूडियो

- **रैंक और प्रगति** — Bronze III से Unreal Legends तक, Builds या Zero Build — मैन्युअल या पब्लिक प्रोफ़ाइल से।
- **OBS ओवरले** — बैनर, फुल या कॉम्पैक्ट। पारदर्शी बैकग्राउंड, ब्राउज़र सोर्स के लिए तैयार।
- **Fortnite Tracker सिंक** — पब्लिक प्रोफ़ाइल का वैकल्पिक रीडआउट। बिना यूज़रनेम मैन्युअल मोड तुरंत चलता है।
- **7 संसार, 6 बैज** — क्लासिक, गैलेक्सी, नियॉन, फ्रॉस्ट, रॉयल, मिनिमल, एस्ट्रल गैलेक्सी। आपके रैंक का चिह्न नहीं बदलता।
- **डिज़ाइन से निजी** — सर्वर केवल 127.0.0.1 सुनता है। यूज़रनेम और इतिहास data/ में हैं, Git उन्हें नज़रअंदाज़ करता है।
- **लाइव सेशन** — स्ट्रीम के दौरान किल, डेथ, स्ट्रीक और रैंक-अप टोस्ट।

## 4 चरणों में चालू

Node.js 18 या नया। Windows पर इंस्टॉल के बाद LANCER.bat काफी है।

```sh
git clone https://github.com/HanaCherry/fortnite-ranked-overlay.git
cd fortnite-ranked-overlay
npm install
npm start
```

http://127.0.0.1:8767

## OBS / Streamlabs

1. ऐप चलाएँ और स्ट्रीम के दौरान खुला रखें।
2. OBS टैब से ओवरले URL कॉपी करें।
3. ब्राउज़र सोर्स जोड़ें।
4. URL चिपकाएँ। डिफ़ॉल्ट बैकग्राउंड पारदर्शी है।

सुझाया आकार: 700 × 220 (बैनर) · 1100 × 220 (फुल)।

## रैंक्ड सिम्युलेटर ऑनलाइन रहता है

प्लेसमेंट, एलिमिनेशन, लेट-गेम और प्रतिद्वंद्वी रैंक से पॉइंट अनुमानित करें। मुफ़्त, बिना इंस्टॉल, आपकी भाषा में।

[सिम्युलेटर खोलें](https://hanacherry.github.io/fortnite-ranked-overlay/simulateur.html?lang=hi)

## लोकल डेटा

शिप किया गया config.json बिना खाते का है। सेटिंग data/config.json में, इतिहास data/state.json में। वह फ़ोल्डर कभी प्रकाशित नहीं होता।
