## Dari simulator ke overlay

Repositori ini bermula sebagai kalkulator mata ranked. Kini studio overlay untuk streamer. Simulator asal kekal di sini, dalam semua bahasa.

## Studio ranked, bukan sekadar kalkulator

- **Rank & kemajuan** — Dari Bronze III ke Unreal Legends, Builds atau Zero Build — manual atau dari profil awam.
- **Overlay OBS** — Sepanduk, penuh atau ringkas. Latar telus, sedia sebagai sumber Pelayar.
- **Sync Fortnite Tracker** — Bacaan profil awam pilihan. Tanpa nama, mod manual terus berfungsi.
- **7 dunia, 6 lencana** — Classic, Galaxy, Neon, Frost, Royal, Minimal, Astral Galaxy. Lambang rank tidak berubah.
- **Peribadi sejak reka bentuk** — Pelayan hanya mendengar 127.0.0.1. Nama dan sejarah dalam data/, diabaikan Git.
- **Sesi langsung** — Kill, death, streak dan toast naik rank semasa stream.

## Sedia dalam 4 langkah

Node.js 18 atau lebih baharu. Di Windows, LANCER.bat memadai selepas pasang.

```sh
git clone https://github.com/HanaCherry/fortnite-ranked-overlay.git
cd fortnite-ranked-overlay
npm install
npm start
```

http://127.0.0.1:8767

## OBS / Streamlabs

1. Jalankan aplikasi dan biarkan terbuka semasa stream.
2. Salin URL overlay dari tab OBS.
3. Tambah sumber Pelayar.
4. Tampal URL. Latar lalai telus.

Saiz cadangan: 700 × 220 (sepanduk) · 1100 × 220 (penuh).

## Simulator ranked kekal dalam talian

Anggar mata dari kedudukan, eliminasi, late game dan rank lawan. Percuma, tanpa pasang, dalam bahasa anda.

[Buka simulator](https://hanacherry.github.io/fortnite-ranked-overlay/simulateur.html?lang=ms)
